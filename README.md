## 📖 Overview

잡지 및 에디토리얼 디자인(Editorial Design Style)에서 영감을 받은 모던 UI/UX 포트폴리오 랜딩 페이지입니다.  
우아한 대형 세리프 타이포그래피, 소프트 섀도우, 은은한 질감 노이즈 오버레이와 함께 핵심 프로젝트 3종을 대화형 카드로 제공합니다.

---

## ✨ Key Features

- 💎 **Modern Editorial Design & Huge Typography**
  - Google Fonts의 `Cormorant Garamond` (Serif)와 `Plus Jakarta Sans` (Sans-serif) 폰트 조합
  - 고급스러운 여백과 번호 매기기, 에디토리얼 잡지 스타일 인터페이스
- 🃏 **3 Featured Project Cards**
  1. **Todo App** — 직관적이고 깔끔한 UI의 모던 할 일 관리 애플리케이션 (`UTILITY`)
  2. **환율 변환기 (Currency Converter)** — 실시간 통화 계산 미니멀 금융 웹 서비스 (`FINTECH`)
  3. **스네이크 게임 (Snake Game)** — 캔버스 기반 레트로 아케이드 게임 (`GAME`)
- 🔗 **Direct Navigation**
  - 각 카드를 클릭하면 해당 프로젝트로 즉시 연결 (`../To do/index.html`, `../fxconveter/index.html`, `../Snake game/index.html`)
- 🔍 **Interactive Category Filter**
  - `ALL WORKS`, `UTILITY`, `FINTECH`, `GAME` 카테고리별 실시간 필터링
- 🌓 **Dark / Light Theme Toggle**
  - 테마 변경 버튼(`◐`)을 통해 다크 모드와 라이트 모드를 자유롭게 전환 (Local Storage 저장 지원)
- ✨ **Dynamic Micro-Interactions & 3D Card Tilt**
  - 마우스 위치에 응답하는 스포트라이트/3D 틸트 호버 애니메이션 및 진입 스크롤 감지 효과

## 🛠️ Tech Stack

- **HTML5**: Semantic Layout & Accessibility
- **CSS3**: Vanilla CSS, Design System Custom Properties, Flexbox & CSS Grid, Animations
- **JavaScript (ES6+)**: Event Delegation, Category Filtering, Theme State Management, IntersectionObserver
