# Modern Editorial Interactive Portfolio

![Portfolio Header Banner](https://img.shields.io/badge/Style-Modern%20Editorial-gold?style=for-the-badge)
![Tech Stack](https://img.shields.io/badge/Stack-HTML5%20%7C%20CSS3%20%7C%20JavaScript-blue?style=for-the-badge)
![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)

사용자 경험(UX)과 에디토리얼 심미성(Editorial Aesthetics)을 극대화한 **모던 인터랙티브 웹 포트폴리오 랜딩 페이지**입니다.  
대형 세리프 타이포그래피, 미니멀 카드 레이아웃, 인터랙티브 3D 틸트 카드, 다크/라이트 모드 테마 전환 및 카테고리 필터링 기능을 포함하고 있습니다.

---

## 🎨 주요 디자인 컨셉 (Design Aesthetic)

- **Huge Elegant Serif Typography**: `Cormorant Garamond` 세리프 체와 `Plus Jakarta Sans` 산세리프 체를 조합하여 잡지/에디토리얼 감성의 기품 있는 비주얼을 제공합니다.
- **Minimalist Card Layout**: 은은한 그라디언트와 글래스모피즘(Glassmorphism) 기반의 UI 목업으로 각 프로젝트의 특성을 시각화했습니다.
- **Soft Ambient Shadows & Noise Texture**: 고급스러운 섬세함을 더하는 에디토리얼 노이즈 텍스처와 부드러운 호버 그림자 효과.
- **Interactive Micro-Interactions**: 마우스 이동에 반응하는 카드 3D 틸트(Tilt) 및 호버 스팟라이트 애니메이션.

---

## 🚀 프로젝트 구성 (Selected Works)

포트폴리오는 3가지 대표 프로젝트 카드로 구성되어 있으며, 각 카드를 클릭하면 해당 앱으로 바로 이동합니다.

| 프로젝트 | 카테고리 | 설명 | 주요 기술 |
| :--- | :--- | :--- | :--- |
| **01. Todo App** | `UTILITY` | 일상의 업무와 목표를 효율적으로 정리하는 모던 할 일 관리 애플리케이션 | HTML5, CSS3, JS |
| **02. 환율 변환기** | `FINTECH` | 실시간 통화 환율 계산 및 변환을 제공하는 미니멀 금융 웹 서비스 | JS, Exchange API |
| **03. 스네이크 게임** | `GAME` | HTML5 Canvas 기반의 고전 아케이드 감성 스네이크 게임 | HTML5 Canvas, JS |

---

## ⚡ 주요 기능 (Features)

1. **프로젝트 원클릭 이동**: 
   - 각 프로젝트 카드를 클릭하거나 키보드(`Enter`, `Space`) 조작 시 해당 프로젝트 페이지로 즉시 이동합니다.
2. **카테고리 필터링 (Category Filter)**:
   - `ALL WORKS`, `UTILITY`, `FINTECH`, `GAME` 카테고리 버튼을 이용하여 해당 항목만 매끄럽게 필터링합니다.
3. **다크 / 라이트 모드 (Theme Toggle)**:
   - 상단 헤더의 테마 버튼(`◐`)으로 밝은 에디토리얼 캔버스 테마와 다크 테마를 자유롭게 전환하며, `localStorage`에 설정이 저장됩니다.
4. **반응형 웹 디자인 (Responsive Design)**:
   - 모바일, 태블릿, 데스크톱 등 다양한 디바이스 해상도에 최적화된 레이아웃을 제공합니다.

## 📁 파일 구조 (Directory Structure)

```text
My-Portfolio/
├── index.html       # 메인 포트폴리오 랜딩 페이지 HTML
├── style.css        # 에디토리얼 디자인 시스템 & 미디어 쿼리 CSS
├── main.js          # 카드 클릭, 필터링, 테마 전환 및 인터랙션 JS
└── README.md        # 프로젝트 설명 문서
```

## 🛠️ 실행 방법 (Getting Started)

별도의 라이브러리 설치나 빌드 과정 없이 웹 브라우저에서 바로 실행할 수 있습니다.

1. 저장소 클론:
   ```bash
   git clone https://github.com/10lilikim/my-portfolio.git
   cd my-portfolio
   ```

2. `index.html` 파일을 라이브 서버(Live Server) 또는 웹 브라우저로 엽니다.
